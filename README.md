A responsive, interactive frontend web application built to deliver a sequential, multi-screen user experience. This project demonstrates state-driven UI transitions, component-based architecture, and gamified web elements using a modern React toolchain.

Originally developed as a personalized interactive greeting application, the codebase is structured to handle dynamic media rendering, user-triggered events, and mini-game mechanics.

🚀 Tech Stack
Framework: React 18
Language: TypeScript
Build Tool: Vite (for rapid hot-module replacement and optimized builds)
Environment: Node.js
Prototyping & UI: Figma AI code generation
✨ Key Features
Sequential UI Routing: A custom 7-screen user flow (including gateway transitions and a grand finale display) without relying on heavy external routing libraries.
Interactive Mini-Game: Embedded state logic to handle user inputs and trigger conditional rendering (gift-dropping mechanics).
Responsive Layout: CSS structuring designed to maintain visual fidelity across mobile and desktop viewport sizes.
Component Modularity: Clean separation of UI components and asset management for scalable development.
🛠️ Run Locally
To run this project on your local machine, ensure you have Node.js installed.
