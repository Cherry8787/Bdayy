Birthday Special Web App

A custom, interactive web application built with love, designed as a special interactive experience and birthday gift. 

---

## 🚀 Tech Stack

This project is built using modern, lightning-fast web technologies:
* **Framework:** [React](https://react.dev/) with [TypeScript](https://www.typescriptlang.org/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Package Manager:** [pnpm](https://pnpm.io/)

---

## 📂 Project Structure

```text
├── src/
│   ├── imports/       # Image assets (memories, buttons, graphics)
│   ├── App.tsx        # Main application component & multi-screen flow
│   ├── main.tsx       # Application entry point
│   └── index.css      # Custom global styles & Tailwind setup
├── public/            # Static assets
├── package.json       # Dependencies & scripts
